# Handy-Texture-Pack-Tools
Early versions of a tool with rather niche functions to help speed up texture pack making.
Please note that this is still very much in an experimental state and may not fully work as intended.

# Requirements
- Python 3 with Tkinter (bundled with the standard python.org installer on
  Windows/macOS; on Linux you may need `sudo apt install python3-tk`).
- pip install pillow numpy
- Optional, for drag-and-drop onto the preview boxes: pip install tkinterdnd2
